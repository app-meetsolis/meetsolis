### Demo Client Data (static)
- [ ] `apps/web/src/lib/onboarding/demo-client-data.ts`:

### Seed Idempotency
```ts
const existing = await supabase
  .from('clients')
  .select('id')
  .eq('user_id', userId)
  .eq('is_demo', true)
  .maybeSingle();
if (existing.data?.id) return { clientId: existing.data.id, alreadySeeded: true };
```
